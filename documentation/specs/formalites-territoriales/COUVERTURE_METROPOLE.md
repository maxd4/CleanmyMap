# Couverture des contacts en France métropolitaine

Statut PLAN / CANDIDATE. Source propriétaire proposée : modules formalities existants, extension CANDIDATS_METROPOLE. Pas de duplication d'annuaire permanent.

| Besoin | Source primaire | Nature |
|---|---|---|
| Compétence administrative | DILA compétence géographique + fiches services | Recherche dynamique candidate |
| Communes traversées | IGN API Carto limites administratives | Intersection géométrique candidate |
| Déchets, collecte, syndicats | BANATIC, ADEME SINOE | Liens d'orientation ; import non réalisé |
| Matériel et reprise | Service de propreté, gestionnaire effectif, associations | Confirmation locale indispensable |
| Associations | World Cleanup Day, JeVeuxAider, Surfrider | Annuaires et réseau, pas inventaire exhaustif |
| Espaces naturels et voies d'eau | OFB, réserves, PNR, VNF | Identifier le gestionnaire compétent |
| Assurance, sécurité | Service Public, assureur, services territoriaux | Information ; aucun accord présumé |

Ne pas générer d'adresse électronique, de compétence ou de délai local non sourcé. Aucun contact ne doit être présenté comme accord. La recherche IGN/DILA reste indépendante des obligations et ne bloque pas une action si indisponible. Les seuils de recherche et les erreurs doivent rester visibles. Voir README_CODEX.md pour les validations et les limites.
