# Système & Utilitaires

Réglages, comparateurs, preview et routes techniques. Les pages standalone gardent une mood layer autonome par usage. La page `/reglages` est la surface secondaire canonique des préférences et paramètres de compte, protégée avec redirection vers `/sign-in` si le compte n'est pas connecté.

## Inventaire des pages

L’inventaire exhaustif des routes canoniques, alias et fiches est tenu dans
[`INDEX.md`](../../INDEX.md). Le contrat de famille runtime est décrit dans
[`PAGE_FAMILIES.md`](../../PAGE_FAMILIES.md).



## Notes

- Les fiches de cette famille suivent le format d'audit standard du dossier `pages_site`.
- Les snapshots de page vivent dans `screenshots/desktop/` ou
  `screenshots/mobile/` sous leur dossier canonique.
