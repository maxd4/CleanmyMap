# Gamification — documentation

Ce dossier documente les contrats et contrôles actuels de la gamification.
Le code runtime fait autorité sur le comportement effectivement déployé.

## Documents actifs

- [Catalogue des badges](BADGE_CATALOG.md)
- [Contrôle d’accès et tests](TESTING_ACCESS_CONTROL.md)
- [Inventaire produit des surfaces gamifiables](../product/gamification-inventory.md)
- [Gamification non compétitive](../product/gamification-non-competitive.md)

Les documents de ce dossier décrivent les badges, leurs contrôles et leurs
frontières techniques. Les documents sous `documentation/product/` portent la
direction produit, l’inventaire et les principes d’usage ; ils ne remplacent
pas les contrats runtime.

Les prototypes et guides de conception retirés du chemin courant sont
conservés dans [`../sessions/history/`](../sessions/history/) avec un bandeau
historique. Ils servent au contexte uniquement et ne doivent pas être utilisés
pour déduire l’architecture actuelle.
